**2. Gestión de Capital Dinámico**

```javascript
/**
 * CAPITAL MANAGEMENT - $5,000 Arbitraje
 */

class CapitalManager {
  constructor(totalCapital = 13000) {
    this.allocation = {
      asian: 0.27,      // $3,500
      meanReversion: 0.27, // $3,500
      usOpen: 0.08,     // $1,000
      arbitraje: 0.38   // $5,000
    };

    this.rebalanceThreshold = 0.1; // 10% desviación
  }

  // Rebalancear mensualmente
  rebalance(currentValues) {
    for (const [system, targetAlloc] of Object.entries(this.allocation)) {
      const currentAlloc = currentValues[system] / this.totalCapital;

      if (Math.abs(currentAlloc - targetAlloc) > this.rebalanceThreshold) {
        // Rebalancear
        const diff = (targetAlloc - currentAlloc) * this.totalCapital;
        this.transferCapital(system, diff);
      }
    }
  }
}
```

    const correlationMatrix = {};

    for (const pair1 of pairs) {
